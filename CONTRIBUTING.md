# Contribuindo com a Dama

1. Crie um fork e uma branch curta para a mudança.
2. Instale com `npm ci`.
3. Execute `npm run build` e os testes relacionados.
4. Abra um pull request explicando comportamento, riscos e validação.

Não envie `dama-engine-payload`, servidores privados, modelos, certificados, tokens, `.env` ou artefatos de `release/`. Mudanças que adicionam permissões, IPC, comandos, downloads ou acesso ao computador devem incluir uma análise explícita de segurança e aprovação do usuário.
