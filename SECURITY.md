# Segurança

Não publique vulnerabilidades, tokens, arquivos de configuração pessoais ou caminhos privados em uma issue pública.

Use o recurso **Security → Report a vulnerability** do repositório para enviar uma descrição, versão afetada, impacto e passos mínimos de reprodução. Não inclua chaves reais nos exemplos.

O repositório público não contém servidores hospedados, credenciais, pesos ou o payload opcional da Dama AI. Tokens configurados no aplicativo devem permanecer cifrados pelo cofre do sistema operacional e nunca devem chegar ao renderer ou aos logs.
